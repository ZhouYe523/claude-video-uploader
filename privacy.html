Privacy Policy

Claude Video Uploader ("the app") is a personal tool used only by the owner of one YouTube channel, on their own computer. Last updated 22 October 2026.

What the app accesses

With the channel owner's permission, the app uses the YouTube Data API to upload videos, set their thumbnails and add subtitle tracks on the owner's channel. It reads the channel's name to confirm it is signed in to the right account. It does not read viewers' data, comments, analytics or any other Google data.

Where data is kept

The app has no server. The sign-in token Google issues is stored only on the owner's computer, encrypted with Windows' built-in data protection. Video files, titles and descriptions are sent only to YouTube. Nothing is sold, shared with third parties or used for advertising.

Uploads are run by Claude, Anthropic's AI assistant, at the owner's request. Information the API returns, such as the channel name and the IDs of new videos, may appear in that Claude conversation.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account → Third-party connections. Deleting the token file from the owner's computer also ends the app's access.
